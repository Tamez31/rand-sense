In the Commission Earner client view, on the Reports tab, add a Finalize Return button at the bottom of the page styled in RandSense primary green #145A32 with white Poppins text. When clicked, query the Supabase invoices table to find the highest existing invoice number in the format RS-00000, increment by one, and assign the next sequential number. Create a record in the invoices table with: client_id from the current client, service_type as "ITR12", tax_year from the selected year dropdown, brochure_price as 550, final_amount as 550, status as "finalized", finalized_date as current timestamp, and the generated sequential invoice_number.
Once finalized, the Reports tab for that selected year switches to READ ONLY. Disable all inputs, toggles, checkboxes and buttons. Replace the Finalize Return button with a Revise Return [Year] button styled with white background and green #145A32 border and text. Clicking Revise Return [Year] re-enables all inputs and deletes the matching invoice record from Supabase where client_id, service_type ITR12, tax_year match and status is finalized. Only allow Revise if status is finalized — not if status is sent or paid.
The READ ONLY state must persist on page refresh. On load, query Supabase invoices for a record matching current client_id, service_type ITR12, and selected tax_year. If status is finalized, render READ ONLY with Revise Return [Year] button. If status is sent or paid, render READ ONLY with no Revise button and show a locked badge only.
Show a mint green #A8E6C1 banner at the top of the Reports tab in READ ONLY mode with dark green text: "Return [YEAR] finalized — Invoice [invoice_number] created." Pull the invoice number from the Supabase record. Only show the discount field on the invoice if a discount amount greater than zero is entered — never display a R0.00 discount line.
