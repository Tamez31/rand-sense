On the Finalize Return button in the Commission Earner Reports tab, add a duplicate check before creating any invoice record. Query Supabase invoices table for an existing record matching the current client_id, service_type ITR12, and selected tax_year. If a record already exists, block the creation, show a red warning banner stating "An invoice already exists for this return. Revise the existing invoice or contact support." and do not create a new record under any circumstances.
On the Practice Dashboard, add a Payment Received button on each client row where the invoice status is finalized or partial and amount_outstanding is greater than zero. When clicked, open a modal showing the client name, invoice number, total invoice amount, amount already paid, and amount outstanding. Include a numeric input field for the practitioner to enter the payment amount received. Validate that the entered amount is greater than zero and does not exceed the amount outstanding.
When the payment is confirmed, insert a record into the Supabase payments table with invoice_id, client_id, amount_paid, and payment_date as current timestamp. Then update the invoices table: add the payment amount to amount_paid and subtract it from amount_outstanding. If amount_outstanding reaches zero, set status to paid and paid_date to current timestamp. If amount_outstanding is still greater than zero, set status to partial.
On the Practice Dashboard metric card for outstanding invoices, only sum invoices where amount_outstanding is greater than zero. Remove any client row invoice indicator from the dashboard where status is paid. On the individual client invoices view, keep all invoice records permanently visible regardless of status. Show the status as a coloured badge — grey for draft, amber for finalized, orange for partial, green for paid. Show paid_date on paid invoices and a running payment history showing each payment amount and date pulled from the payments table.
