On the Practice Dashboard, each client row that has an outstanding invoice must show a Payment Received button styled in primary green #145A32 with white Poppins text. When clicked, open a modal showing: client name, invoice number, total invoice amount, amount already paid, and amount outstanding — all pulled live from the Supabase invoices and payments tables. Inside the modal include a numeric input field labelled "Amount Received" and a Fully Paid button in mint green #A8E6C1 with dark green text. When Fully Paid is clicked, automatically populate the input field with the full outstanding amount. Validate that any entered amount is greater than zero and does not exceed the amount outstanding — show a clear red error message if validation fails.
When payment is confirmed, insert a record into the Supabase payments table with invoice_id, client_id, amount_paid, and payment_date as current timestamp. Then update the invoices table: add the payment to amount_paid, subtract from amount_outstanding. If amount_outstanding reaches zero set status to paid and paid_date to current timestamp. If amount_outstanding is still greater than zero set status to partial. Close the modal and refresh the dashboard data from Supabase without a full page reload.
On the Practice Dashboard outstanding invoices metric card, query Supabase invoices table and sum only records where amount_outstanding is greater than zero. This total must refresh every time a payment is recorded. Client rows where invoice status is paid must remove the Payment Received button and show a green Paid badge instead with the paid_date displayed beneath it in small grey text.
Inside the individual client screen, add an Invoices tab between IRP6 and Settings. This tab must list all invoices for that client pulled from Supabase, showing invoice number, service type, tax year, total amount, amount paid, amount outstanding, status badge, and created date. Below each invoice show a payment history table pulled from the Supabase payments table showing each payment amount and date. Invoices with status paid must show paid_date. Status badges: grey for draft, amber for finalized, orange for partial, green for paid.
